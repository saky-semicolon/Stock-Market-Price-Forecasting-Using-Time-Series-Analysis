# 📈 Stock Market Price Forecasting Using Time Series Analysis

This project implements stock price forecasting using advanced time series analysis techniques. It compares the performance of the **SARIMAX** statistical model and the **LSTM** deep learning model to predict future stock prices based on historical data. The aim is to explore each model's forecasting accuracy and real-world applicability in financial decision-making.

## 🔍 Project Overview

Stock prices are inherently volatile and influenced by various factors. Accurately forecasting them is a challenging yet valuable task. This project:
- Analyzes historical stock price data.
- Applies SARIMAX for statistical time series forecasting.
- Builds an LSTM model to capture complex temporal patterns.
- Compares their performance using key error metrics.


## ✅ Features

- Time series decomposition: trend, seasonality, and residuals.
- Augmented Dickey-Fuller test for stationarity.
- Rolling window forecasting using SARIMAX.
- Sequential training and prediction using LSTM.
- Visualization of actual vs. predicted stock prices.
- Evaluation using RMSE and MAE metrics.
